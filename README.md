# JobFinder AI

Static GitHub Pages preview of the JobFinder AI frontend.

## Run locally
Open `index.html` in a browser or use VS Code Live Server. The project uses Firebase web configuration for authentication/data; Firebase rules and the GitHub Pages domain must be configured in the Firebase console for those features.

## Live preview
https://bavanbali.github.io/JobFinder-AI/

## Limitations
GitHub Pages only hosts the static frontend. Configure Firebase Auth authorized domains and secure database rules before using account or job-data features. This repository does not include private credentials.
